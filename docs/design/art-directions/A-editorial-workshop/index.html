Plate 02 · Agent Toolkit

One source → many assistants

Reusable agent capabilities: skills, subagents, loops, and profiles that install into Cursor, Claude Code, OpenCode, and Gemini CLI without rewriting the nest for each tool.

61 skills
16 agents
10 loops
6 profiles

Copper note — causality, not chrome: a request selects a recipe (pair / team / full), which assigns roles, opens worktrees, and produces governed artifacts.

  1. 01Request arrives with intent and constraints
  2. 02Recipe: pair · team · full swarm
  3. 03Roles bind to skills; worktrees isolate change
  4. 04Handoffs + state → governance → artifact
