# Generated Create Awesome compatibility data

`compatibility.json` is generated from immutable, pinned copies of the canonical
`cna-templates`, `cpa-templates`, and `cva-templates` registries.

Do not edit the snapshot or the pinned source cache manually.

```sh
pnpm data:create-awesome:refresh
pnpm data:create-awesome:check
```

The normal website build reads only the committed snapshot and never contacts
GitHub. See `scripts/data/create-awesome/README.md` for the refresh contract.
